# 35. 위험·안전·거버넌스

> 자기 개선 시스템은 "더 좋아지는 능력"만큼 "잘못된 것을 더 잘하게 되는 능력"도 갖는다. 이 문서는 새 프레임워크의 위험을 목록화하고, 각 위험을 **어느 장치가 구조적으로 막는지**를 정한다.

---

## 2. XGEN 전용 critic 규칙 (RRSI 6규칙에 추가)

RRSI critic 의 6규칙(누설, 퇴화, 채점기 게이밍, 미선언 번들링, 런타임 메모리/스킬 누설, 무한 작업)을 그대로 쓰고 다음을 더한다.

7. **권한·거부 우회 유도**: 사용자 거부·권한 차단·HITL 을 피해 같은 효과를 내도록 모델을 이끄는 문구·메커니즘(예: "차단되면 다른 도구로 같은 일을 하라").
8. **커널 영역 침범**: 커널 한도·원장·검증기·이벤트 계약·자격증명에 영향을 주려는 편집(구조적으로 막히지만 의도 자체를 거부 사유로 기록).
9. **고객·업무 특화**: 특정 고객사명·업무 용어·사내 시스템명 하드코딩(RRSI 의 "엔티티명" 을 XGEN 다중 테넌트로 확장).
10. **언어·문구 규범 위반**: 사용자에게 보이는 안내 문구는 기존 규범(시스템 내부 사정 노출 금지 등)을 따른다 — 사용자 노출 문구는 커널 상수이므로 하네스 편집 대상이 아님을 명시.

결정적 precheck 패턴(초안): 평가 태스크 id·제목 전체, 검증기·judge 경로/이름, 자격증명 패턴(공식 코드 공통 패턴 + XGEN 키 형식), 고객사명 목록(관리자 제공), 내부 호스트명.

## 3. 거버넌스 — 누가 무엇을 결정하는가

| 결정 | 주체 | 근거 기록 |
|---|---|---|
| 하네스 후보 판정(허용/불허) | **수식**(rsi_math) | decisions.json(입력 전부) |
| 운영 승격(H\*, π_E\*) | **사람**(MR/PR 승인) | 승격 보고서 |
| 헌법(SKILL.md)·패턴·critic 규칙 | 사람 | 하네스 저장소 버전 |
| 하이퍼파라미터(δ 제외) | 사람(evolve·운영 고려만, held-out 미참조) | rrsi.json 버전 + 이유 |
| δ | calibrate 실측 | calibration.json |
| 평가 세트 구성 | 사람 | 도메인 버전 |
| lineage 표 | 승격 파이프라인(사람 승인 후 자동) | lineage 이력 |
| 엔진 전환(pipeline21 ↔ rsi) | 사람(관리자 설정) | 설정 변경 이력 |

배포 규범(기존 그대로): 모든 변경은 사람 승인(MR/PR 리뷰·머지) 후 CI 로만 운영에 반영한다.

## 4. 감사 가능성

- 모든 운영 하네스 버전은 불변 보관(내용 주소). 어떤 턴이 어떤 H·π_E·정책으로 돌았는지 recorder 에 남는다.
- 모든 진화 결정은 재판정 가능(판정 입력 저장).
- 모든 정책 호출은 원장에 purpose 와 함께 남는다(비용 감사).
- 승격 보고서: 후보 diff(구성요소 주소 단위), Algorithm 2 판정 근거(바닥·분기·값), held-out/OOD 결과(판정 미사용 명시), 비용 변화, 위험 체크리스트.

## 5. 중단 스위치

| 스위치 | 효과 |
|---|---|
| 호스트가 `AgentTurnExecutor` 로 되돌림 | 즉시 기존 엔진(롤백) — 기존 런타임은 처음부터 그대로다 |
